Creatives

Add videos or images, set where they’ll run, and run the checks. Each creative gets a verdict: launch, fix first, or cut, with the reasons.

Drop video (MP4, MOV, WebM) or image files here. Files stay in this browser; only sampled frames are sent to your AI provider when you run checks.

Scripts & copy

Check a video script or an image creative’s text before anything is produced. Each one gets a verdict, the reasons, and suggested rewrites.

Brain scores

Import the JSON written by tribe_preflight.py. Scores match creatives by file name and are ranked against every scored creative in your library.

Brain scores predict how an average viewer’s cortex responds, second by second. They say nothing about your offer, price or audience, and emotion isn’t measured. Treat them as a ranking aid until calibration confirms they track your results.

Calibrate

Upload past results from Ads Manager. The tool checks which scores actually tracked thumb-stop rate, hold rate and CTR on your account, and forecasts new creatives only from the ones that did.

ad_name,impressions,video_plays_3s,thruplays,link_clicks,spend,results

ad_name must match the creative’s file name without its extension. Each past ad also needs brain scores imported.

Compare

Pick up to three variants to see side by side.

Settings

Paste an API key and click Connect. The tool asks the provider which models your key can use and picks one. Keys are saved only in this browser and sent only to the provider you choose.

Tool version 2.1 (29 Oct 2026). If you don’t see version 2.1 after uploading a new file, press Ctrl+F5.

Backup

Everything is stored in this browser only. Download a backup before clearing your browser or moving to another computer.

Rules
